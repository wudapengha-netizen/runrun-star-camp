# 部署说明：让记录在任何设备上都能用

做完这一套，效果是：**任何电脑、平板、手机，打开同一个网址，就是润润最新的进度。**

分两半：
- **网页**放 GitHub Pages（免费）
- **学习记录**放 Cloudflare Workers + KV（免费额度远远够用）

全程大约 20 分钟。两个都不需要绑银行卡。

---

## 第一步：发布网页到 GitHub Pages

### 1. 登录 GitHub 命令行

打开一个**终端窗口**（PowerShell 或 CMD 都行），运行：

```bash
gh auth login
```

按提示选：`GitHub.com` → `HTTPS` → `Y`（用浏览器登录）→ 回车，
浏览器会打开让你授权，照做就行。

> 这一步必须你自己做，我这边跑不了浏览器授权。

### 2. 创建仓库并推上去

在 `study` 文件夹里运行：

```bash
gh repo create runrun-camp --public --source=. --remote=origin --push
```

想要仓库不公开就把 `--public` 换成 `--private`。
⚠️ 但注意：**GitHub 免费版即使仓库私有，Pages 网站仍然是公开可访问的**，
带访问控制的私有 Pages 是企业版功能。

### 3. 打开 Pages

```bash
gh api -X POST repos/:owner/runrun-camp/pages -f "source[branch]=main" -f "source[path]=/"
```

等一两分钟，网址就是：

```
https://你的GitHub用户名.github.io/runrun-camp/
```

这时候网页已经能在任何设备打开了，但**记录还是各存各的**。继续下一步。

---

## 第二步：部署云端存档

### 1. 注册 Cloudflare

去 https://dash.cloudflare.com/sign-up 注册，邮箱验证一下就行，不用绑卡。

### 2. 登录命令行

在 `study/cloud` 文件夹里运行：

```bash
npx wrangler login
```

浏览器会打开让你授权。

### 3. 创建存记录的 KV

```bash
npx wrangler kv namespace create SAVES
```

会打印出类似这样一行：

```
id = "a1b2c3d4e5f6...."
```

把这个 id 复制下来，**填进 `cloud/wrangler.toml`**，替换掉那句
`id = "把这里换成你自己的 KV id"`。

### 4. 设置配对码

配对码就是你自己定的一串字，用来保护润润的记录不被别人读写。
中文、英文、数字都行，建议 8 位以上，别用生日这种能猜到的。

```bash
npx wrangler secret put CAMP_KEY
```

它会让你输入，输完回车。**记住这串字**，后面每台设备要输一次。

### 5. 部署

```bash
npx wrangler deploy
```

成功后会打印出你的 Worker 网址，形如：

```
https://runrun-camp-save.你的名字.workers.dev
```

### 6. 把网址填进网页

打开 `study/data/cloud.js`，把那个网址填进去：

```js
window.CLOUD = {
  url: 'https://runrun-camp-save.你的名字.workers.dev',
  profile: null
};
```

⚠️ **配对码千万别写进这个文件** —— 这个文件会发布到 GitHub，谁都能看源码。

### 7. 重新推送

```bash
git add data/cloud.js
git commit -m "接上云端存档"
git push
```

---

## 第三步：每台设备连一次

在任何设备上打开网址，会自动弹出输入框，输入你刚才设的**配对码**，点连接。
一台设备只用输一次，之后就记住了。

右上角的存档灯会变成 **☁️**，表示进度存在云端。

没输配对码的人打开这个网址，也能玩，但**读不到也改不了润润的记录**
（他们只会存在自己浏览器里）。

---

## 各种情况会怎么样

| 情况 | 表现 |
|---|---|
| 正常联网 | ☁️ 进度实时同步，任何设备打开都是最新的 |
| 断网 / 信号差 | 📴 照常做题，记录存本机，联网后自动补传（30 秒起退避重试） |
| 两台设备同时用 | 比时间戳保留较新的一份，并在界面上明确告诉你，不会闷声丢数据 |
| 配对码没输 / 输错 | 🔑 提示重新输入，记录暂存本机 |
| 没配云端，双击 start.bat | 🗄️ 存成 `save/润润.json` 文件，可以配合云盘同步 |
| 没配云端，双击 index.html | 📌 只存这个浏览器里，界面会明确说"换设备带不走" |

## 免费额度够不够

Cloudflare Workers 免费版：每天 10 万次请求、KV 每天 1000 次写入。

润润一天做 45 道题，存档做了防抖（800 毫秒合并一次），
实际大概每天几十次写入 —— **用不到免费额度的 5%**。

## 记得备份

云端每次覆盖前会自动留一份快照（保留 20 份 / 90 天）。
但保险起见，还是建议**每周去家长端点一次「⬇ 导出存档」**，
在自己电脑上留个 json 文件。

## 不想折腾云端怎么办

那就别做第二步。把整个 `study` 文件夹放进 OneDrive / 坚果云同步目录，
每台电脑双击 `start.bat`，记录会存成文件跟着云盘走。
够用，而且完全不依赖任何第三方服务。
