# 润润的三年级闯关营

一个给小学三年级孩子做的暑假自学网页：把**语文 / 数学 / 英语**三门课的知识点
拆成 31 天关卡，用积分、等级、称号、礼花和 Boss 战让孩子愿意每天按时学。

对着 2024 新版教材编写：部编版语文三上、人教版数学三上、人教版 PEP 英语三上。

![闯关地图](docs/preview.png)

## 特点

- **纯静态**，没有构建步骤，双击 `index.html` 就能用，断网也能用
- **汉字笔顺动画**：写字表 250 个字点开就能看一笔一画，还能用鼠标描红跟写
- **朗读全靠浏览器自带语音**：课文逐句朗读高亮、英语单词发音、听力题现场读两遍，
  不需要任何音频文件
- **音效是现场合成的**：答对叮咚、连击升调、升级号角、金币声，
  用 Web Audio 算出来，零音频文件零版权问题
- **礼花特效**：自写 canvas 粒子，不依赖任何第三方库
- **错题本 + 艾宾浩斯回顾**：答错自动入库，第二天开场重考，连对两次才"毕业"
- **逐题流水账**：每答一题记一条（时间、知识点、对错、用时），
  家长端能看出每个知识点练了多少、最近稳不稳
- **三种存档后端**，自动选、自动降级：
  云端（任何设备同一份进度）→ 本地文件（配合云盘同步）→ 浏览器存储

## 怎么用

最简单：双击 `index.html`。

想让记录能跨设备，见 [`docs/部署说明.md`](docs/部署说明.md)。

## 目录

```
index.html      孩子用的主界面（31 天闯关地图）
parent.html     家长端学习报告
serve.py        本地服务器，把记录存成真文件
start.bat       一键启动（Windows）
css/            设计系统 + 游戏化组件
js/             引擎：存档 / 音效 / 特效 / 朗读 / 题型 / 笔顺 / 小结
data/           每日内容、课表、等级、配置
vendor/         hanzi-writer + 写字表 438 字的笔顺数据（本地打包，离线可用）
```

## 技术上值得一提的地方

- **`file://` 下也能跑完整功能**。笔顺数据没走 hanzi-writer 默认的 CDN 加载，
  而是预打包进 `vendor/hanzi-data.js`，通过 `charDataLoader` 从内存读 ——
  否则 `file://` 下 XHR 会被浏览器拦掉。
- **配对码走 base64**。HTTP 请求头只允许 ISO-8859-1，
  中文配对码直接塞进头里会让 `fetch` 抛错，所以统一转 base64 再传。
- **存档冲突不静默丢数据**。两台设备都改过时，服务端返回 409 并带回它那份，
  客户端比时间戳决定采用哪份，并在界面上明确告诉用户发生了什么。
